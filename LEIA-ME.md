# GO! · como está organizado

- `index.html` → site de apresentação (usegoapp.com.br)
- `app.html` → o aplicativo (usegoapp.com.br/app)
- `privacidade.html` e `termos.html` → páginas legais
- `sw.js` → notificações e funcionamento sem internet
- `config.js` → endereço do Supabase e e-mail de contato (campo contactEmail)
- `img/` e `video/` → imagens e vídeo do site
- `vercel.json` → faz /app abrir o app.html

## Pra atualizar
GitHub → goapp → Add file → Upload files → arraste os arquivos (e pastas) → Commit changes.
O Vercel publica sozinho em ~1 minuto.
